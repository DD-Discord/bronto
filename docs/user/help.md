# Using /help

`/help` shows help for the bot and for the modules your server has turned on.

Without options, it opens this page. Add a `module` to open that module's start page. Add a `topic` as well to open one topic. Both options suggest names as you type.

Only you can see the answer. Nobody else in the channel gets a message.

---

## Menus and buttons

Under each page there are two menus. The first one switches module. The second one switches topic. The current choice is already selected.

If a topic has more than one page, you also get **Back** and **Next**. The grey button between them shows where you are, like `1 / 3`.

Some pages have a button next to a short text. It opens a related topic or a web page.
