# Modules

Modules add commands to the bot. An administrator decides which ones your server uses.

Only administrators can use `/modules`. Everyone else can still read about enabled modules with `/help`.

## Commands

- `/modules list` shows every module and whether it is on.
- `/modules enable` turns a module on. Its commands appear in your server.
- `/modules disable` turns a module off. Its commands disappear. Its saved data stays.

Turning a module back on brings the data back.
