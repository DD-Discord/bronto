# Note commands

All commands start with `/notes` and need the Manage Messages permission.

## Writing notes

- `/notes create` adds a note with a title and a text.
- `/notes edit` changes the title or the text.
- `/notes edit-text` opens a form for a longer text.
- `/notes delete` removes a note.

## Reading notes

- `/notes list` shows all notes.
- `/notes show` shows one note in full.
- `/notes post` posts a note in the channel with a **Read** button. Whoever presses it sees the text privately.
