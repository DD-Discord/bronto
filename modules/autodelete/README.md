# @bronto/autodelete

Keeps one post per member in a channel, enforces a cooldown between posts and removes a member's posts when they leave. Each channel has its own rule, edited with `/autodelete`.

- Using `/autodelete`: run `/help` in Discord and pick Autodelete.
- Loading the module, permissions and config: [docs/admin/setup.md](docs/admin/setup.md)
