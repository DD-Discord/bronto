# @bronto/templates

Message templates (text and one embed) that live as posts in a forum channel. Members with access create and edit templates in Discord; other modules read them through an API. The sticky module uses it for its messages.

- Using templates: run `/help` in Discord and pick Templates.
- Loading the module and its permissions: [docs/admin/setup.md](docs/admin/setup.md)
- API, events and gates for other modules: [docs/api/index.md](docs/api/index.md)
