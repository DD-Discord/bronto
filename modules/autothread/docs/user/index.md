# Autothread

Opens a thread on every new post in a channel, for example so that replies to announcements or screenshots stay out of the main conversation. A thread can start with a message from a template. Other modules can also hand autothread a message, such as a form submission, to get the channel's thread as if a member had posted it.

Each channel has its own rule. Moderators manage rules with `/autothread` and need the Manage Channels permission by default.

> [!section] [Open](setup.md)
> **`/autothread set`, `show`, `list`, `remove`**
> Create or change a rule, look at the rules of your server or remove one.

> [!section] [Open](rename.md)
> **Rename button**
> Let the author of a post rename their thread.
