# Renaming a thread

With `rename` turned on in a rule, each new thread gets a **Rename thread** button. It sits on the first message of the thread, or on a short message of its own when the rule has no first message.

- Only the author of the post can use it. Everyone else is told so.
- The button opens a form with the thread's name, 1 to 100 characters. Submitting it renames the thread.
- Discord allows two renames per thread every 10 minutes. After that the author is told when to try again.
- The button keeps working after the bot restarts.

The bot needs the Manage Threads permission to rename threads.
