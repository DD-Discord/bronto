# Autoreact

Adds the same emoji reactions to every post in a channel or thread, for example a thumbs up and down under each suggestion. Other modules can also hand autoreact a message, such as a form submission, to get the channel's reactions as if a member had posted it.

Each channel or thread has its own rule. Moderators manage rules with `/autoreact` and need the Manage Channels permission by default.

> [!section] [Open](setup.md)
> **`/autoreact set`, `show`, `list`, `remove`**
> Create or change a rule, look at the rules of your server or remove one.
