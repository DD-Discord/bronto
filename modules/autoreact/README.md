# @bronto/autoreact

Adds fixed emoji reactions to every post in a channel or thread. Each channel has its own rule, edited with `/autoreact`.

- Using `/autoreact`: run `/help` in Discord and pick Autoreact.
- Loading the module, permissions and behavior next to other modules: [docs/admin/setup.md](docs/admin/setup.md)
- Other modules can add a channel rule's reactions to a message they posted for someone through the `reactPost(message, author)` API.
