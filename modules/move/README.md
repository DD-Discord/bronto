# @bronto/move

Moves a range of messages to another channel or thread: reposted under the authors' names and avatars with their files and reactions, then deleted from the source. Moderators run `/move` and confirm first.

- Using `/move`: run `/help` in Discord and pick Move.
- Loading the module, permissions and behavior next to other modules: [docs/admin/setup.md](docs/admin/setup.md)
